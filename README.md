# OwliaBot Docs

Documentation site for [OwliaBot](https://github.com/owliabot/owliabot) - a Crypto-Native AI Agent.

🌐 **Live site**: [docs.owlia.bot](https://docs.owlia.bot)

## About OwliaBot

OwliaBot is a self-hosted AI agent designed for crypto users, featuring:

- 🔐 **Three-tier security model** for safe key management
- 💬 **Telegram & Discord** as primary channels
- 🛠️ **Extensible skills system** for custom functionality
- ⚡ **Minimal dependencies** (< 30 direct deps)

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

## Tech Stack

- [Astro](https://astro.build) + [Starlight](https://starlight.astro.build) for documentation
- Deployed on Cloudflare Pages
