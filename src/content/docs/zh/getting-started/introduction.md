OwliaBot 是一个**自托管、原生加密（crypto-native）的 AI 代理**，专为重视安全与掌控力的加密用户设计。

## 为什么选择 OwliaBot？

### 🔐 安全优先

私钥**永远不会进入机器人进程**。OwliaBot 使用三层安全模型：

| 层级 | 类型 | 使用场景 |
|------|------|----------|
| 1 | 伴生 App | 需要用户确认的交易 |
| 2 | 会话密钥 | 小额自动化操作（gas、领取奖励等） |
| 3 | 智能合约钱包 | 大额自动化操作，且可细粒度授权 |

### 🏠 自托管

完全运行在你自己的机器或服务器上。没有云端依赖，也没有第三方能接触你的数据。

### 🔌 可扩展

通过 **Skills** 扩展能力——使用 JavaScript 模块为代理添加功能。你可以自己编写，也可以从社区安装。

### 📱 熟悉的交互方式

通过 **Telegram** 或 **Discord** 与你的代理对话。无需学习新应用。

## 它如何工作

```
你（Telegram/Discord）
        │
        ▼
┌──────────────────────┐
│     OwliaBot         │
│                      │
│  ┌────────────────┐  │
│  │ Skills         │  │ ← 可扩展
│  │ - crypto-price │  │
│  │ - dex-swap     │  │
│  └────────────────┘  │
│                      │
│  ┌────────────────┐  │
│  │ Signer         │  │ ← 更安全
│  │（三层模型）     │  │
│  └────────────────┘  │
└──────────────────────┘
```
